source (text) → Mach-O 工具 (step 1–9) → ELF bootstrap @ step 10 → ELF in → ELF/Mach-O out (step 12+)
核心 insight：ct-ng framework 設了 18 個 hook，但對「glibc + cross toolchain type」這個組合，只有 13 個會實際跑。標 ✗ 的 5 個（7, 11, 13, 16, 17）framework 留著但 no-op 或 skip。
◆ 跨格式 bridge：step 3, 6, 9, 12 的 binary 自己是 Mac Mach-O（跑在 Mac 上）但操作 x86_64 ELF。這是 cross-toolchain 的核心 trick——--host 控制 binary 自己格式，--target 控制 binary 操作的格式，兩條軸正交。Step 15 反過來：binary 自己是 ELF（跑在 target Linux 上）也操作 ELF。
